# App do Comprador · Planejar Assessoria

App (Android/iOS) para os compradores da Planejar Assessoria acompanharem parcelas, boletos, Pix e documentos, e painel web para a equipe. Integração com o Asaas via Supabase.

A especificação, as decisões e o passo a passo para rodar estão no [CLAUDE.md](CLAUDE.md).

| Pasta | O que é |
|---|---|
| `apps/mobile` | App do comprador (Expo SDK 58) |
| `apps/admin` | Painel da equipe (Vite + React), publicado na Vercel |
| `packages/shared` | Tipos e formatação compartilhados |
| `supabase` | Migrations, Edge Functions e configuração |
| `docs` | Marca e protótipo aprovado |

Desenvolvido por Nexla Automação e Inteligência Artificial.
