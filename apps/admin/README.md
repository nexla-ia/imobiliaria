# Painel da equipe (Vite + React + Tailwind)

- Configuração: `.env.local` na raiz do repositório com `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY`.
- Rodar: `pnpm admin` na raiz (ou `npx vite` aqui).
- Vercel: Root Directory `apps/admin`, framework Vite; as mesmas duas variáveis no projeto da Vercel. O `vercel.json` manda todas as rotas para o `index.html`.
